SRTT Analysis

The goal of SRTTAnalysis is to provide a set of R functions for analysing raw reaction time data, particularly data from the Serial Reaction Time Task (SRTT).

I created and currently use the package to process and filter reaction time data, calculate performance measures such as skill across different task phases, and examine the percentage of filtered values. The functions can work with both wide and long data formats and can be applied to individual datasets or dataframes containing multiple participants. The package also includes functions for plotting reaction time data and skill measures, allowing me to examine changes in performance across the different stages of an SRTT.
