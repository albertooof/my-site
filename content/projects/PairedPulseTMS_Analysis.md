The goal of [**PairedPulse TMS Analysis**](https://github.com/albertooof/PairedPulseTMS_Analysis) package is to provide a set of R functions for analysing and normalising *raw paired-pulse TMS data*.

I created and currently use the package to process paired-pulse measurements, organise test stimulus and conditioned stimulus responses, and apply different **normalisation methods** to the data. The functions can work with both *wide* and *long* data formats and can be applied to individual datasets or dataframes containing multiple participants. The package also includes functions for plotting the normalised data, allowing me to visualise the responses across different triggers and compare the results between participants.
